# One Piece Character Search API Project

A project I built that takes in data from an api about One Piece Characters and allows a user to filter through characters using a search bar feature.
Users can also click on each character card to navigate to a screen that provides more data on each character if available.

Steps to View:
  Clone repository
  npm install
  npm run dev

I hope you enjoy and can learn a little about some One Piece Characters!
